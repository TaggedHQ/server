Import / Export

Export

Download all your time records as a CSV file — useful for backups, processing, or moving your data elsewhere.

Date-time format

Import

Paste table data (from a CSV/text file or directly from Excel) below, or drop a .csv file onto the field. Columns can be separated by tab, comma, or semicolon — the separator is detected automatically.

See the import format

The first row must be a header naming the columns. Column names are case-insensitive, and values may be wrapped in double quotes.

ColumnAccepted namesRequired
Startstart, beginRequired
Stopstop, endRequired*
DurationdurationOptional*
Tagstag, tags, projectOptional
Descriptiondescription, ds, comment, title, summaryOptional
DatedateOptional
Keykey, idOptional

* Each record needs a stop time or a duration.

  • Times accept a Unix timestamp or a date-time string (e.g. ISO 8601). When a date column is present, start/stop may be a plain hh:mm time.
  • Duration accepts h:mm, h:mm:ss, or a number of seconds, and is used when there is no stop time.
  • Tags and project names become #tags; any #tags already in the description are merged in.
  • Keys let you update existing records: a matching key (or an exact start/stop match) replaces the record instead of adding a new one.

Example

key,start,stop,tags,description
abc123,2026-07-12 09:00,2026-07-12 11:00,#work #dev,Feature build
,2026-07-12 13:00,1:30,#meeting,Sprint review
